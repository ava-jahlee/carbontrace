# carbontrace · 감사자용 walkthrough

> **누구를 위한 문서인가**
>
> 이 문서는 사업자가 carbontrace 로 산정한 온실가스 배출량을 검증하는
> **제3자 검증기관·감사자·심사원** 을 위한 것.
>
> "이 숫자가 왜 이 값인가" 를 클릭 몇 번으로 원문서까지 추적할 수 있도록
> 도구가 설계돼 있다. 이 walkthrough 는 그 사용법을 보여 준다.

---

## 원칙

carbontrace 는 다음 3층 구조를 지킨다.

1. **결과 값 (`∑ tCO2eq`)** — 사업자가 보고하는 최종 숫자
2. **중간 계산** — 그 결과를 만든 수식 · 대입된 각 계수
3. **원문서 (primary source)** — IPCC PDF · GIR 공식자료 · K-ETS 지침 등

각 층은 다음 층으로 클릭 한 번에 이동할 수 있어야 한다.
"엑셀 셀 클릭 → 수식" 감사성을 웹에서 재현.

---

## 감사 워크플로우 · 표준 5단계

### 1. 대상 값 확인

사업자가 제출한 계산 조건을 그대로 재현.

- Scope 1 (연료 연소): `/scope1`
- Scope 2 (전력·열): `/scope2`
- Scope 1 fugitive (냉매): `/refrigerant`

각 계산기 왼쪽 입력 패널에 사업자가 사용한 조건을 그대로 입력:
- 연료·활동원 · 사용량 · Tier · GWP 기준
- Scope 1 은 추가로 **데이터 프로파일** (원본 xlsm / xlsm-corrected / gir22-latest) 확인

**주의:** 사업자가 어떤 프로파일을 사용했는지 명시하지 않았다면 물어봐야 한다.
프로파일마다 결과가 다르기 때문 (등유 · 항공유 · 매립지가스 등에서 큰 차이).

### 2. 감사 신뢰도 요약 카드 확인

결과 카드 바로 아래의 **감사 신뢰도 요약** 카드에서:

- **성숙도 분포 바** — verified (초록) / documented (파랑) / asserted (황) / pending (회색) 비율
- **N건 계수 사용 · N개 원문서 참조**
- **warning 목록** — ⚠ 로 표시된 primary source (원출처 확인 필요)

**감사 판단 기준:**
- verified 100% 인 계산이면 원문서 재확인만으로 검증 완료
- warning 이 있으면 그 원문서를 열어 사업자와 협의 필요 (특히 원본 xlsm 오작성)
- asserted 가 많으면 원문서 재확인 결과에 따라 사업자에게 재산정 권고

### 3. 각 계수 근거 확인 (Cell 팝오버)

결과 화면 각 숫자 옆의 `i` 버튼을 누르면 팝오버가 열린다.

팝오버 내용:
- **결과값** — 이 셀의 최종 값
- **수식** — 어떤 식으로 계산됐는가 (예: "사용량 × 열량계수 × 배출계수 × 산화계수 × 10⁻⁶")
- **대입된 값** — 각 인자별 종류·값·단위
  - 파란 배지 `계수` : Measurement · 원문서 근거 있음
  - 황색 배지 `파생` : 하위 계산 결과 (다시 파고들기 가능)
  - 초록 배지 `입력` : 사용자 직접 입력
  - 회색 배지 `상수` : 물리 상수 · 관례
- **원문서 근거 카드** — 발행처 · 판 · 표 · 페이지 · 행 · **원문서 열기 링크**
  - 성숙도 배지 (확정/문서화/주장/미조사)
  - warning 인 경우 카드 전체 강조 + ⚠ 배지

### 4. 원문서 링크 클릭 → 재확인

Primary source 카드의 **원문서 열기 ↗** 링크를 누르면 IPCC PDF · GIR 게시글 · K-ETS 고시 등이
새 탭으로 열린다. 표·페이지·행 정보를 카드에서 확인한 뒤 원문서에서 해당 값 재확인.

**검증 완료 판단:** 원문서의 값과 팝오버의 값이 일치하면 그 계수는 검증됨.

### 5. 파생값 재귀 추적

만약 어떤 값이 "파생" 이라면 (예: tGHG · tCO2eq), 팝오버 안에서 다시 `파고들기 ▸` 를 눌러
그 파생값의 계산 과정으로 진입. 최종적으로 모든 값은 primary source 또는 사용자 입력에 도달.

## 예시 · 아역청탄 1 ton 감사

**조건**: Scope 1 · 아역청탄(하위 유연탄) · 1 ton · 열량 T1 · 배출 T2 · GWP SAR · 프로파일 xlsm-original

**결과**: ∑ tCO2eq = 1.924820

### 감사 단계

1. **감사 요약 카드**:
   - 8건 계수 · 5개 원문서
   - verified 100%
   - warning 없음
   - → 이 결과는 원문서 재확인만으로 검증 가능

2. **CO₂ 카드 · 배출계수 `i` 버튼**:
   - 팝오버 열림 → 값 97049.33 kgGHG/TJ
   - 원문서 근거: **K-ETS 별표 12 · 표 A · 아역청탄 · CO2 파생값**
   - 계수 근거 = tC 24.83 × 44/12 × 1000
   - 확인일자 명시

3. **원문서 열기 ↗** → K-ETS 고시 PDF 열림 → 표 A 아역청탄 tC 값 재확인

4. **tCO2eq 카드** → `파고들기 ▸`:
   - tGHG = 1.7975... × GWP 1
   - tGHG 카드 안에서 다시 `파고들기 ▸` → 사용량 × 열량계수 × 배출계수 × 산화계수 × 10⁻⁶

## 예시 · 등유 1 kL 감사 (⚠ 원본 xlsm 오작성)

**조건**: 등유 (기타 등유) · 1 kL · T1/T2 · SAR · xlsm-original

**결과**: ∑ tCO2eq = 3.186254

### 감사에서 발견되는 문제

1. **감사 요약 카드**:
   - 확정 88% · 주장 13% (1건)
   - warning 1건: "⚠ xlsm 원본 오작성 (뒤바꿈)"
   - → 이 값은 재확인 필요

2. **CO₂ 카드 · 배출계수 `i` 버튼**:
   - 팝오버 배출계수 카드에 ⚠ 배지 · 카드 강조
   - note: "xlsm 원본 오작성. 저자가 등유·항공유 값을 뒤바꿔 넣음.
      정확한 별표 12 등유 = 19,969 kgC/TJ (73,153 kgCO2/TJ)"

3. **감사 조치**:
   - 사업자에게 **데이터 프로파일 `xlsm-corrected` 로 재산정** 권고
   - `xlsm-corrected` 로 재계산하면 배출계수 = 73,153 (원본 73,080 대신) → 결과 tCO2eq = 3.189430 로 변경됨

## 데이터 프로파일별 신뢰 지침

Scope 1 계산기의 데이터 프로파일 선택은 감사 시 반드시 확인:

| 프로파일 | 감사 의미 |
|---|---|
| `xlsm-original` | 원본 xlsm 값 그대로. 파리티 테스트 통과. 다만 등유·항공유·석탄 N2O·가스류 등에서 원본 오류 함께 유지. warning 배지 확인 필수. |
| `xlsm-corrected` | 원본 오류 정정 (별표 12 · IPCC Table 2.5 기준). 국가고유 값은 xlsm 이 담은 GIR 2017년 판 유지. |
| `gir22-latest` | 정정 + GIR 2022.1 공표 최신 값. K-ETS 배출권거래제 최신 실무에 가장 부합. |

## Scope 별 감사 체크리스트

### Scope 1 (연료 연소)

- [ ] 연료 종류 · 사용량 · 활동 단위 (ton/kL/천m³) 확인
- [ ] Tier 선택 (T1/T2/T3)
- [ ] T3 인 경우 사업자 실측치 근거 요구 (사업자 측정 계획서 등)
- [ ] 데이터 프로파일 확인
- [ ] 감사 요약 warning 확인
- [ ] 각 계수 원문서 링크로 재확인
- [ ] GWP 기준 (SAR / AR4 / AR5 / AR6) 확인

### Scope 2 (전력 · 열)

**전력**:
- [ ] GIR 승인 판 (2017 / 2022) 확인
- [ ] 발전단 · 소비단 확인 (소비단이 T&D loss 포함)
- [ ] 최신 판 (2024년 승인 · 2023년 판) 미반영 상태 인지

**열 (KDHC)**:
- [ ] 지사 · 계획기간 (3기 / 4기) 확인
- [ ] KDHC 원문 (연간 공시) 재확인

**열 (국가 통합)**:
- [ ] 이 3종 값은 원출처 미상 (asserted). 감사 시 KDHC 지사별 값 사용 권장

### Scope 1 fugitive (냉매)

- [ ] 냉매 ID · 유출량 (kg) 확인 (사업자 재충전 대장·폐기 서류)
- [ ] GWP 판 확인 (K-ETS 실무 = SAR)
- [ ] 블렌드 냉매 GWP 계산 방식 확인 (mass 비율 가중)

## 재현성 검증

carbontrace 는 원본 xlsm 과의 파리티를 Vitest 로 자동 검증:

```bash
npm test   # 137/137 PASS 확인
```

특히 파리티 테스트:
- `tests/scope1.parity.test.ts` — 아역청탄 1 ton · 원본 xlsm 값과 소수점 10 자리 이상 일치
- `tests/scope2.parity.test.ts` — KDHC 4기 수도권지사 1 TJ · xlsm Main D42 = 35.991 tCO2 정확 재현

감사 시 이 테스트를 재실행해서 재현성 확인 가능.

## 감사 결과 문서화 지원

각 primary source 카드에서 다음 정보를 감사 보고서에 그대로 옮길 수 있다:

- 발행처
- 판·판별 (예: "2022년 승인 · 2023년 공표")
- 표·페이지·행
- URL (원문서 링크)
- 확인일자 (`reviewedAt`)
- 성숙도 (verified / documented / asserted / pending)
- 특이사항 (`note` 필드)

이 정보들이 그대로 감사 근거자료로 사용 가능.
